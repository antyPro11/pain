# 疼痛专科护士培训刷题小程序

根据《2026年疼痛专科护士培训班教材》设计的刷题小程序，共 **201 道**单选题，帮助掌握疼痛护理核心知识点。

## 快速开始

本项目为纯静态页面，无需安装依赖、无需构建。

**直接打开方式**：
- 用浏览器打开 `index.html` 即可开始刷题（推荐 Chrome / Edge / 360 等主流浏览器）

（也可以在本目录启动本地服务后访问，例如 `python -m http.server 8091`，然后访问 `http://localhost:8091`）

## 功能

- **四种刷题模式**：顺序刷题、随机刷题、错题重做、模拟考试（随机抽 20 题 + 20 分钟限时）
- **模块筛选**：按 7 大知识模块单独练习或全部练习
- **答题判分**：选择答案即时判分，显示答案解析
- **答题卡**：可视化答题进度（答对/答错/未答）
- **错题本**：自动记录错题，可反复重做，答对自动移出错题
- **进度统计**：记录累计练习数与正确率
- **本地存储**：进度与错题保存在浏览器本地，关闭后不丢失

## PWA（可装到手机桌面）

本项目已配置为 PWA，支持「添加到主屏幕」，安装后像原生 App 一样全屏运行、离线刷题。

新增文件：
- `manifest.json` — PWA 清单（名称、图标、配色）
- `service-worker.js` — 离线缓存（stale-while-revalidate 策略）
- `icon.jpg` — 应用图标
- `.nojekyll` — 告诉 GitHub Pages 不要用 Jekyll 处理

**iPhone 使用方法**：用 Safari 打开网址 → 底部分享按钮 →「添加到主屏幕」→ 桌面出现图标，点开即用。

> 更新题目或代码后，将 `service-worker.js` 中的 `CACHE` 版本号 +1（如 `pain-quiz-v2`），用户下次打开会自动拉取最新版。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `pain-quiz`）
2. 将本项目所有文件上传到仓库
3. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
4. 等待 1~2 分钟，访问 `https://你的用户名.github.io/pain-quiz/`
